# `krateoctl`

`krateoctl` is the official CLI for the Krateo Platform: it handles installation, upgrade,
migration, and version-aware composition operations, driving a Kubernetes cluster from a
declarative `krateo.yaml`.

## Quick install

### Linux / macOS (curl)

```sh
curl -sL https://raw.githubusercontent.com/krateoplatformops/krateoctl/main/install.sh | bash
```

### macOS (Homebrew)

```sh
brew tap krateoplatformops/krateoctl
brew install krateoctl
```

For Windows or manual installation, download the archive for your OS/architecture from the
[Releases](https://github.com/krateoplatformops/krateoctl/releases) page and add the binary to your `PATH`.
